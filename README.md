# LitVibe — Class 10 English website, Version 3

Responsive static website with:
- 9 First Flight prose guides
- 10 First Flight poem guides
- 9 Footprints Without Feet guides
- Search and collection filters
- Original summaries, themes, character notes, poem explanations and literary-device lists
- Responsive layout and lesson detail dialogs

## Preview
Open `index.html` in a modern browser. No build tools are required.

## Free publishing
1. Create a GitHub repository named `litvibe`.
2. Upload `index.html`, `styles.css`, `content.js`, and `app.js` to its root.
3. In Settings → Pages, select deployment from branch `main`, folder `/ (root)`, and save.
4. Use the free GitHub Pages URL. A custom domain is optional.

## Editorial and syllabus note
The Class 10 chapter list follows the CBSE English Language & Literature prescribed-book list for academic year 2026–27. Verify the current CBSE notification and school syllabus before treating any chapter as examinable. This is an independent resource and is not affiliated with NCERT or CBSE. All explanations are original learning notes. Do not reproduce complete textbook passages, poems, illustrations or exercise pages.

## Content update in Version 3
The chapter **A Letter to God** now includes learning goals, a detailed summary, theme and character analysis, paraphrased textbook-exercise prompts with detailed answers, short- and long-answer practice, competency questions with revealable explanations, exam-writing guidance and quick revision. Other chapters remain starter guides and will be expanded in later releases.

## Technical limits
Static front-end only; no admin panel, database, user accounts, payments, comments or automated content management yet. Edit `content.js` to update the lesson library.
